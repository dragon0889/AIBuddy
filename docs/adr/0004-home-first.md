# ADR-0004: Triển khai đầu tiên tại nhà (phụ huynh là chủ tài khoản)

- Trạng thái: Chấp nhận (theo xác nhận của chủ sản phẩm)
- Quyết định: phụ huynh đăng ký/xác thực trước, tạo hồ sơ con; thiết bị dùng chung chuyển hồ sơ bằng biểu tượng + PIN; cổng giáo viên lùi sang Pha 2.
- Hệ quả: nội dung phải tự đủ (không có giáo viên); mỗi bài có hướng dẫn phụ huynh (bắt buộc bởi schema).
